# 설치 및 실행 가이드 (v3.0)

1. **로컬 실행 (Mac / Windows / Linux)**: `ChoiceOfGod_v3.0.zip` 압축을 풀고 `index.html`을 더블 클릭하거나 `scripts/Play_Mac.command` / `Play_Windows.bat` / `Play_Linux.sh`를 실행하세요.
2. **웹 / 스마트폰 앱(PWA)**: `https://karan211-bruno.github.io/choice-of-god/` 접속 후 Chrome/Safari 메뉴에서 **「앱 설치」 / 「홈 화면에 추가」** 선택.
3. **데스크톱 설치 파일(.dmg / .exe / .AppImage)**: `cd desktop && npm install && npm run dist:mac` (또는 `dist:win` / `dist:linux`).
