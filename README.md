## 🔥 v5.1 주요 개선 사항

1. **클릭 이동 + 자동 전투 + 즉각 액션 반응성 강화**
   - **1장. 에덴동산**: 땅·별·천사·뱀을 클릭하면 아담이 그 자리까지 직접 질주해 줍고 대화하며 3단 검기 콤보를 날립니다! 툴바에 **자동 전투(`🤖 자동 전투 ON/OFF`)** 토글 추가!
   - **2장. 노아의 방주**: 방주 짓기 버튼을 누르거나 타일을 클릭하면 노아가 직접 달려가 도약 망치질을 수행하며, 대기 중에도 건물들을 순찰·수리해 +1 보너스 자원을 모읍니다!
   - **3장. 아브라함**: 맵의 어느 육각 타일이든 클릭하면 BFS 최단 경로를 따라 한 칸씩 걸어가며, 약탈자 조우 시 격돌 연출이 펼쳐집니다!
   - **4장. 모세와 10재앙**: 순간이동 없는 **4단계 물리 안무**(전방 질주 돌진 → 도약 기적 시전 & 넉백 → 복귀 도약, 적 턴 바로/술사 동일 질주 반격!).
   - **5장. 홍해 도하**: 소환 시 하늘 빛기둥 낙하 착지 + 아군 근접 교전 시 전방 돌진 타격 & 애굽 전차 넉백 반동!
   - **6장. 시내산**: 하단 전경에 **살아 움직이는 풀바디 모세 & 수호천사**가 커서를 따라 스텝을 밟고 지팡이를 들어 빛 탄환을 발사!
   - **브라우저 입력 & 타이틀**: 캔버스 클릭/스테이지 진입 시 버튼 포커스 자동 해제로 `Space` 키가 즉시 캐릭터 액션을 발동하며, 5개 언어 `metaTitle`을 **v5.1**로 일괄 갱신했습니다.
