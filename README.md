## 🗺️ v6.0 주요 업데이트

1. **성경 전체 월드맵 기반 스테이지 선택 허브 (`assets/bg/world_map.jpg`)**
   - 에덴동산 → 아라랏 산 · 노아의 방주 → 가나안 · 모리아 산 → 애굽 · 나일강 → 홍해 도하 → 시내산으로 이어지는 16:9 2.5D 핸드페인팅 월드맵과 황금 점선 여정 루트.
   - 6명의 4등신 SD 영웅 핀과 클리어 별점/왕관 배지를 지도 위에 직접 배치해 원하는 장을 자유롭게 선택할 수 있습니다.
2. **첫 화면 실시간 스테이지 브리핑 패널 (`#stage-briefing-panel`)**
   - 지도 핀을 클릭하면 곧바로 전투로 들어가지 않고, 첫 화면 오른쪽 패널에서 선택한 지역 배경·영웅·장르 배지·스토리 설명·미션 목표·장르별 조작법·핵심 성경 말씀을 즉시 미리 볼 수 있습니다.
   - `이전` / `다음 스테이지` 버튼 순환, 핀 더블클릭 즉시 출발, `이 모험 시작하기` 골든 버튼 지원!
