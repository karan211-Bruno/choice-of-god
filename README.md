## ⚔️ v2.0 리메이크 핵심 특징

1. **6개 광활한 오픈필드(1920×1280) & 자유로운 시점 이동**
   - 월드맵(`[M]`)에서 **아담과 하와(에덴)**, **노아(방주 계곡)**, **아브라함(가나안·모리아 산)**, **모세(고센·홍해·시내산)** 시점과 지역을 언제든 자유롭게 오갈 수 있습니다.
   - 커스텀 일러스트 Canvas 그래픽과 실시간 미니맵, 6개 다단계 보스전을 지원합니다.

2. **위쳐 3 스타일 분기 대화 & 에덴의 갈림길**
   - NPC·성소와의 `[E]` 대화를 통해 믿음·지혜·긍휼 선택지를 고릅니다.
   - **에덴 수호 루트 (`+5,000` 왕관 보너스)**: 1장에서 선악과 유혹을 물리치고 **고대 뱀 보스**를 정화하면 영원한 에덴 천국을 완성합니다.
   - **역사의 여정 루트**: 선악과를 선택해도 게임은 끝나지 않고 **긍휼의 가죽옷**을 입고 창세기~출애굽기 구원 서사로 이어집니다.

3. **실시간 액션 전투 · 스킬 트리 · 3슬롯 성물 장비 · 천사 가이드**
   - **이동**: `WASD` / 방향키 (모바일 터치패드 지원)
   - **기본 공격**: `Space` / `J` / 화면 클릭
   - **회피 질주 (무적)**: `Shift` / `K`
   - **3대 스킬 (`1`·`2`·`3`)**: 빛의 말씀 파동 · 기적 지팡이 광선 · 생명나무 은총 치유 (`[C]` 창에서 레벨업!)
   - **3슬롯 성물 장착 (무기 · 의복 · 성물)** 및 레벨에 따라 합류하는 **5명의 동행 천사 가이드**가 실제 전투 능력치(공격력·방어력·마력재생·속도·점수)를 올려줍니다.

4. **게임 내 5개 국어 실시간 전환**
   - 한국어(`ko`), English(`en`), 日本語(`ja`), Español(`es`), 中文(`zh`) — 새로고침 없이 즉시 전환.
