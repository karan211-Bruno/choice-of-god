## 🎨 v4.0 그래픽 리마스터 주요 특징

1. **상용 2D 방치형 RPG 스타일 풀바디 SD 치비 스프라이트 (21종 RGBA 투명 컷아웃)**
   - 아담, 노아, 아브라함, 모세, 아론, 미리암, 수호 천사, 방패 기사, 보스 뱀, 파라오, 애굽 주술사, 전차, 아기 양·사자 및 Top-War 풍 2.5D 아이소메트릭 건물 7종(`assets/sprites/*.png`)을 Canvas 위에서 호흡·도약·검기 이펙트·`Lv.X` 배지와 함께 애니메이션!

2. **6개 스테이지 전용 2.5D 페인팅 월드 배경 (`assets/bg/*.jpg`, 960×540)**
   - **1장. 에덴동산 (아담과 하와)** — ⚔️ **액션 RPG** (에덴 섬 배경, Y-정렬 생명나무·선악과나무, 뱀 보스전 & +5,000 왕관 분기)
   - **2장. 노아의 방주 (노아)** — 🏡 **2.5D 아이소메트릭 건설 시뮬레이션** (Top War 풍 다이아몬드 타일 건설·터치 `Lv.1→Lv.3` 업그레이드 & 초록 `↑` 화살표·아기 동물 행진)
   - **3장. 아브라함 (아브라함)** — ♟️ **헥스 턴제 전략** (가나안 오아시스 위 반투명 2.5D 헥스 타일 · 롯 외교 · 별빛 성소 · 모리아 산 성막)
   - **4장. 모세와 10재앙 (모세)** — 🃏 **JRPG 턴제 전투** (이집트 신전 안뜰 사이드뷰 배틀 · 풀바디 SD 모세·아론 vs 파라오·주술사)
   - **5장. 홍해 도하 (모세와 미리암)** — 🛡️ **실시간 전략 RTS** (갈라진 청록빛 바다 벽 사이 3개 물길 디펜스 · 전차 보스전)
   - **6장. 시내산 (모세)** — ✨ **1인칭 빛 조준 슈팅 & 성막 피날레** (시내산 황금 성막 수호 · 만나 수집 · 다중 엔딩)

3. **게임 내 5개 국어 실시간 전환 (`ko` / `en` / `ja` / `es` / `zh`) & 성경 말씀 32구절 도감**
