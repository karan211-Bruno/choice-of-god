## 🔥 v5.0 애니메이션 & 액션 게임성 대개편

1. **11종 캐릭터 4프레임 액션 스프라이트 시트 (`assets/sprites/sheets/*_sheet.png`, 880×220 RGBA)**
   - 아담, 노아, 아브라함, 모세, 아론, 미리암, 수호천사, 방패기사, 보스 뱀, 파라오, 애굽 주술사가 대기 → 질주 스트라이드 A/B → 무기 휘두름/마법 시전 전용 포즈로 생동감 있게 움직입니다!
   - 카메라 화면 흔들림(`shake`), 히트스톱(`hitstop`), 대시 잔상, 발자국 먼지, 포물선 자원 오브, 콤보·크리티컬 팝업을 통합 처리하는 `js/engine/vfx.js` 추가.

2. **6개 스테이지 액션/전략 심화**
   - **1장. 에덴동산 (액션 RPG)**: 3연속 빛 검기 콤보 + 3타 관통 검기파, `Q` 빛의 회오리, `R` 천사 광선+회복, 보스 뱀 돌진 예고·3갈래 구슬 반사 패링!
   - **2장. 노아의 방주 (2.5D 아이소메트릭 건설)**: 클릭한 타일로 노아가 직접 달려가 망치질하며 건설·`Lv.3` 업그레이드, 축복 소나기·해변 표류 목재(`+4 🪵`) 이벤트, 날아드는 자원 오브!
   - **3장. 아브라함 (헥스 전략)**: 부드러운 보행 이동, 애굽 약탈자 순찰 및 정면 격돌 연출, `별빛 번개`/`화평의 사절` 액티브 전략 스킬, 성소-모리아 산 빛 연결선!
   - **4장. 모세와 10재앙 (JRPG 전투)**: 모세 돌진/복귀 액션, 5대 기적 전용 연출(홍수 파도·개구리 행진·하늘 우박·회전 방패·유월절 빛기둥), 파라오 행동 예고 & `BREAK!` 약점 파훼!
   - **5장. 홍해 도하 (실시간 전략 RTS)**: 천사 검기·방패기사 넉백·미리암 음표 힐·전차 투창 투사체·물벽 붕괴 파도 + `1/2/3`, `Q/W/E/R` 단축키 지원!
   - **6장. 시내산 (1인칭 슈팅 & 피날레)**: 4연속 명중 시 3발 피버 모드, `Shift` 시내산 영광 광선 필살기, 2페이즈 그림자 뱀 수호자 보스전!

3. **Network-First 서비스 워커 (`sw.js` `choice-of-god-v5.0.0`)**
   - HTML/JS/CSS는 네트워크 우선 조회로 업데이트 즉시 반영되며 오프라인/로컬 `file://`에서도 동일하게 작동합니다.
